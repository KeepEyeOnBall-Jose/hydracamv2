# Prioritize managed Android fleet control

HydraCam promises near-real-time background observability and command execution
for Managed Fleet Phones on Android, accepting the operational cost of device
management to obtain a reliable fleet control plane. iOS remains a supported
Reduced-Control Phone platform whose durable Sync work can continue through
platform-scheduled transfer and foreground execution, but HydraCam does not
claim equivalent command timing where iOS does not provide an always-running
application service.
